# Medical Inventory & Prescription Management System

## Overview

The Medical Inventory & Prescription Management System is a database-driven web application developed to simplify medicine inventory, supplier management, and prescription handling for clinics and pharmacies.

The system maintains medicine records, supplier information, patient prescriptions, and inventory details while supporting CRUD operations and SQL-based data retrieval.

---

## Features

- Medicine inventory management
- Supplier management
- Prescription management
- CRUD operations
- Low stock monitoring
- Relational database design

## How to Run

1. Install XAMPP.

2. Copy the project folder into the **htdocs** directory.

3. Import the MySQL database using phpMyAdmin.

4. Start Apache and MySQL.

5. Open the application in your browser.

```
http://localhost/Medical-Inventory-System/
```
